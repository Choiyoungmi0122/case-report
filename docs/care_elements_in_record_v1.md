# CARE 요소별 기록 내용 정리 (실험 사례, 전문가 확인 전)

- 대상: 실험 사례(68세 여자, 6회 방문)의 **치료 개입**과 **추적 관찰 및 결과**
- 용도: 참여자가 AI 초안을 보기 전에 쓴 초안에 CARE가 요구하는 요소가 얼마나 들어 있었는지, AI 초안과 비교한 뒤 무엇을 더 떠올렸는지 정리할 때 쓰는 기준
- 작성: 2026-10-05, 세션 시작 전. 생성형 AI(Claude)가 원기록을 CARE 세부 항목별로 정리. 인용한 구절은 방문별 원문 파일에서 검색해 확인함
- 상태: **임상 전문가 확인 전**

## 이 문서의 관점

이 연구는 증례보고를 써 본 적이 거의 없는 한의사가 **쓰는 법을 배우는 과정**을 본다. AI의 틀린 곳을 얼마나 잘 찾아내는지는 연구의 중심이 아니다. 그래서 이 문서는 "AI 초안의 오류 목록"이 아니라 "이 사례의 기록에 CARE 요소별로 무엇이 있는가"를 정리한다.

분석에서 보는 것은 두 가지다.

1. **처음 쓴 초안에 무엇이 들어 있었나.** 초보자가 스스로 떠올리는 요소와 빠뜨리는 요소.
2. **비교한 뒤 무엇을 더 떠올렸나.** "내 초안과 AI 초안을 비교해 보니", "AI 초안에 빠진 내용"에 적은 내용과 인터뷰에서 말한 내용.

점수로 쓰지 않는다. 요소를 많이 쓴 참여자가 잘한 것이라고 해석하지 않는다. 두세 문장만 쓰라고 안내했으므로 모든 요소를 쓸 수 없다. 어떤 요소가 자주 떠오르고 어떤 요소가 잘 떠오르지 않는지를 보는 것이 목적이다.

## 참고: AI 초안은 각 요소를 어떻게 다뤘나

모든 참여자에게 같은 AI 초안이 제공된다. 참여자가 비교할 때 무엇을 볼 수 있었는지 알기 위한 참고 정보다.

| CARE 세부 항목 | AI 초안 | 기록과 견주면 |
|---|---|---|
| 9a 종류 | 한약, 침, 약침, 물리요법, 상담, 자율훈련법, 정신과·신경과 약을 나열함 | 정신과 재진 권유와 생활 지도는 없음 |
| 9b 시행 방법 | 유침 20분, 자율훈련법 횟수, 쿠에티아핀 용량은 있음 | 한약 용량과 복용법, 약침 용량, 침 규격, 기존 약의 이름과 용량은 없음. 날짜를 "4월 초", "4월 중순"으로 씀 |
| 9c 변경과 이유 | 쿠에티아핀 추가, 딸의 복약 관리, 월 1회 계획은 있음 | 약침 중단과 그 이유, 도네페질 복용 시간 변경, 태양 추가는 없음. 침 치료가 없던 기간을 "4월 말 이후"로 씀(기록은 4/15 이후) |
| 10a 평가한 결과 | 척도의 처음과 끝 값, 6회차의 호전을 씀 | 3월 말과 4/10의 악화는 없음. 5회차 척도 값은 없음. 환자와 딸의 말을 구분하지 않음. 치료 외에 달라진 생활은 없음 |
| 10b 추적 검사 | 없음 | K-MMSE가 그대로인 점, HRV, 혈압이 모두 없음 |
| 10c 순응과 내약성 | 4월 초부터 복약이 규칙적이었다고 씀 | 그 전의 불규칙 복용, 예약 미내원은 없음. 자율훈련법을 "병행되었다"고 씀(기록은 교육만) |
| 10d 이상반응 | 안와부 멍과 "그 외 특이 이상반응은 관찰되지 않았다"를 씀 | 기록과 일치함 |
| 앞으로의 계획 | "경과를 관찰하고 있으며", "지속하고 있다"로 씀 | 기록은 계획과 안내임 |

## 참여자별 기록 양식

칸마다 두 가지를 적는다.

- **초안**: AI를 보기 전에 쓴 초안에 그 요소가 있었는가. ○(썼음) / △(일부) / ×(없음)
- **비교 후**: AI 초안과 비교한 뒤 그 요소를 언급했는가. 언급한 곳을 적는다. 비(비교해 보니) / 빠(AI 초안에 빠진 내용) / 표(문장 표시) / 인(인터뷰) / -(언급 없음)

| 실험번호 | 9a 종류 | 9b 방법 | 9c 변경과 이유 | 10a 평가 결과 | 10b 추적 검사 | 10c 순응 | 10d 이상반응 |
|---|---|---|---|---|---|---|---|
| (예) T1 초안 | ○ | × | × | ○ | × | × | △ |
| (예) T1 비교 후 | - | 비 | 빠 | - | 빠 | 인 | - |
| | | | | | | | |

같이 적어 둘 것:

- 참여자가 "비교해 보니"에 쓴 문장 전체
- 근거 보기("기록에서 관련된 부분 보기")와 AI 메모 추천을 펼쳐 봤는지
- 인터뷰에서 "무엇을 써야 하는지 알게 됐다"는 취지로 말한 내용

## 이 정리로 말할 수 있는 것과 없는 것

말할 수 있는 것:

- 초보자가 처음 쓴 초안에 자주 들어간 요소와 잘 들어가지 않은 요소
- AI 초안, CARE 기준, 작성 예를 본 뒤 새로 언급한 요소
- 참여자가 스스로 말한 "알게 된 것"

말할 수 없는 것:

- 작성 능력이 향상되었다 (한 번의 세션이고 비교 조건이 없다)
- 요소를 많이 쓴 참여자가 더 잘 배웠다 (두세 문장으로 제한했다)
- AI 초안과의 차이를 표시한 횟수가 검토 능력을 나타낸다 (이 연구가 보려는 것이 아니다)

## 한계

- **어떤 내용을 어느 세부 항목에 넣을지는 해석이 갈릴 수 있다.** 예를 들어 "치료 외에 달라진 생활"을 10a에 넣었지만 고찰(11c)에 넣는 것이 맞을 수 있다.
- **한의학적 관점의 요소는 다루지 않았다.** 변증의 근거, 처방 구성, 혈위 선택의 이유를 치료 개입에 넣어야 하는지는 전문가가 판단해야 한다.
- **정리한 것도 생성형 AI다.** 인용 구절은 원문에서 확인했지만 분류는 사람이 다시 봐야 한다.
