# Scaffold V2 'AI 메모 추천' 세트의 작성 기준과 근거 (검수 전)

Scaffold V2(시스템 버전 v3.0, 교수 평가·학생 후속)에서 1단계(기록 읽기)에 제공하는 추천 메모의 근거 문서다. V1 세트의 문서 `memo_suggestions_basis.md`와 같은 역할을 하며, 작성 기준은 그 문서 §3을 그대로 따른다. 문구를 고치면 코드(`backend/src/study/cases/defaultStudyCaseMemoSuggestionsV2.ts`)와 이 표를 함께 고친다.

## 1. V1과 다른 점

| 항목 | V1 (학생 S1~S10) | V2 |
|---|---|---|
| 개수 | 12개, 방문마다 2개 | 22개, 방문마다 3~4개 |
| CARE 범위 | 5c, 7, 8a, 9a, 9c, 10a, 10b, 10c | **9a, 9b, 9c만** (치료 개입 섹션만 실습하므로) |
| 화면 정보 | 종류(눈에 띈 점/더 확인할 점) + 문구 | 종류 + 문구 + **CARE 세부 항목 배지 + 회차 + "원문에서 보기"**(가리키는 구절을 원기록에서 강조) |
| id | v1-1 … v6-2 | ti-1-1 … ti-6-4 (V1 id는 학생 기록이 참조하므로 그대로 둔다) |
| 가리키는 구절 | 요약·생략 포함 가능 | **원기록에 그대로 있는 구절**이어야 한다. `npm run test:study`가 검사한다 |
| 공개 방식 | 회차별 접힘, 눌러서 펼침 | 같다 (요청 시 공개 유지) |
| 채택 시 저장 | 메모 id 접두어 `case-note-ai-`로만 구분 | `origin: 'ai_suggestion'`, `suggestionId`, `visitIndex`, `careItems`가 메모에 함께 저장된다 |

V1 추천 12개 가운데 치료 개입과 관련된 5개(v1-2, v2-1, v3-2, v5-1, v5-2)는 V2에서 같은 지점을 가리키는 항목으로 다시 썼다(ti-1-1, ti-2-1, ti-3-1, ti-5-1, ti-5-2). 추적 관찰·진단·타임라인 관련 7개는 V2에 없다.

## 2. 어떻게 만들어졌나 (사실 그대로)

1. 2026-10-11 생성형 AI(Claude)가 가상환자 EMR 원문(6회차)과 이미 검수된 고정 자료 — CARE 세부 항목별 기록 정리표(`DEFAULT_STUDY_CARE_ELEMENT_MAP` 치료 개입 9a/9b/9c)와 충분성 질문별 원문 인용(`DEFAULT_STUDY_RECORD_POINTERS` ti_001~003) — 를 바탕으로 22개 초안을 썼다.
2. 각 추천의 "가리키는 구절"이 해당 방문 원기록에 글자 그대로 있는지 자동 테스트로 확인했다(22개 모두 통과).
3. **연구자 검수와 임상 전문가 검토는 아직 거치지 않았다.** 검수 후 날짜와 수정 내용을 여기에 적는다. 교수 평가용 V2를 고정하기 전에 검수를 끝내야 한다.

개수(회차당 3~4개, 총 22개)의 근거: 치료 개입 기록 정리표의 "기록에 있는 정보" 12항과 원문 인용 18개가 6회차에 걸쳐 분포하는 지점을 중복 없이 하나씩 가리키면 22개가 된다. V1의 "방문마다 2개"와 마찬가지로 경험적 선택이며, 교수 평가에서 과하다는 의견이 나오면 줄인다.

## 4. 고정 AI 초안과의 관계 (중복 점검)

치료 개입 고정 AI 초안(504자)은 9a·9b·9c 내용을 거의 전부 담고 있어, 원기록을 가리키는 추천은 모두 초안의 어느 문장과 겹친다. 추천은 **값·결론을 적지 않고 "어디를 보라"만 말하므로** 초안 문장을 미리 보여 주는 것은 아니다. 다만 추천을 모두 펼쳐 채택한 학습자의 메모 목록은 초안의 뼈대와 비슷해질 수 있다. 교수 평가에서는 "추천을 몇 개 펼쳤는가"가 `memo_suggestion_opened` 이벤트로 남고, 채택 메모는 `origin: 'ai_suggestion'`으로 구분된다.

## 5. 기준에 비춘 한계

- **기준 6(이상반응 10d 제외)**: 6회차 약침 이상반응 자체는 가리키지 않는다. ti-6-3은 "하지 않은 치료"(9c)만 가리키고 이유는 쓰지 않는다. 학습자가 이상반응과 그 연관을 스스로 찾는지는 그대로 관찰 대상이다.
- **기준 4(값·결론 금지)**: ti-5-3 "다시 처방되었다", ti-4-2 "실제로 이루어졌다는 기록이 있다"는 기록에 적힌 사실을 그대로 말한 것이지만, 추천이 사실 진술에 가까워진 사례다. 검수에서 더 중립적인 문구로 바꿀 수 있다.
- **다루지 않는 것**: 한의학적 변증·처방 구성 근거, 치료 선택의 임상적 타당성. 추천은 "기록에 무엇이 어디에 적혀 있는가"에 한정된다.
- **9c가 4개로 적다.** 치료 변경과 이유(9c)는 선행연구에서 보고율이 가장 낮았던 항목(최성열 2020 27.3%, Kim 2017 25.8%)이다. 검수 시 9a 일부를 9c 관점으로 바꾸는 것을 검토할 수 있다(예: ti-4-3을 "권유"가 아니라 "치료 계획 변경"으로).
