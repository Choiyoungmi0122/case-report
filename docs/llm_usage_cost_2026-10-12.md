  - 이 77건을 포함해도 비용 차이는 0.005 USD(약 7원)뿐이다. 호출 수만 부풀린다.

## 2026-10-12부터: 사례(세션)별 비용

이제 호출 기록마다 사례 id(`caseId`)가 남는다. 원고 검토는 `manuscriptReviewId`가 남는다.
- **기록 방식:** 서버가 요청 경로에서 사례 id를 읽어 그 요청의 모든 LLM·임베딩 호출 기록에 붙인다. 응답 뒤에 계속 도는 사례 처리와 최종 원고 작업도 포함한다(`backend/src/llm/usageContext.ts`).
- **기록만 하는 용도:** 체인 동작에는 영향이 없다.
- **이전 기록:** 사례 id 없이 남은 기록은 "(사례 id 없음)"으로 묶인다.

```bash
npm run usage:summary -- --db --since 2026-10-12
```

- `--db`: MongoDB에서 사례의 실험 번호와 종류를 읽어 붙인다. 종류는 실험용 Write, 실험용 Scaffold v3.0, 일반 Scaffold, 일반 Write다. 읽기만 하고, 사례 제목은 싣지 않는다.
- `--since`: 그 시각(UTC ISO) 이후 기록만 센다.
- 참가자 한 명의 세션 비용은 그 참가자 사례의 행 하나다. 실험 번호로 찾는다.
- 캐시 할인은 OpenAI가 돌려준 `cached_tokens` 기준이다. 실제 청구액과는 반올림·요금제 차이가 있을 수 있다.
