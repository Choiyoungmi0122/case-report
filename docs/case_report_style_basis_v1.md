# 실험용 Write 초안 문체·구성 근거 (v1, 2026-10-12)

실험용 Write 의 섹션 초안(SW-D), 고쳐 쓰기(SW-R), 질문(SW-Q2) 프롬프트와 섹션별 쓰기 규칙(`backend/src/studyWrite/careItems.ts` 의 `CARE_SECTION_WRITING_RULES`)에 국내 한의 학술지 증례보고의 서술 관례를 반영했다. 근거 논문은 다음 5편이다 (연구실 제공 PDF).

| 학회지 | 주제 |
|---|---|
| 대한한방내과학회지 41(6), 2020 | 뇌경색 후 지남력장애·현훈, 성향정기산가미방 |
| 한방신경정신과학회지 31(3), 2020 | 제2형 양극성 장애 주요우울 삽화, 복합 한방 치료 |
| 대한한방내과학회지 45(2), 2024 | 길랑바레증후군, 침·전침 |
| 대한한방내과학회지 45(2), 2024 | COVID-19 후 알츠하이머 치매 악화, 억간산가미 |
| 대한한방내과학회지 45(2), 2024 | 섬유근육통 불면, 분심기음 |

예시는 특정 과에 치우치지 않도록 짧고 일반적인 것만 넣었다. 논문 문장을 옮기지 않았다.

## 근거의 두 층 (2026-10-12 추가)

쓰기 규칙은 두 자료를 함께 쓴다.

| 자료 | 역할 |
|---|---|
| CARE 설명 문서 원문(Riley 등, J Clin Epidemiol 2017;89:218-235, 사용자 제공 PDF) | 섹션마다 무엇을 써야 하는가 |
| 위 국내 증례보고 5편 (CARE 를 따라 쓴 논문) | 그것을 국내 한의 학술지에서 어떻게 쓰는가(문체, 순서, 표기) |

우선순위(사용자 결정 2026-10-12): **제1조건은 CARE 가이드라인의 세부 항목을 완수하는 것**, **제2조건은 제1조건을 지키면서 위 논문들의 형식을 따르는 것**이다. 같은 내용을 초안·고쳐 쓰기 프롬프트(SW-D·SW-R v7)의 "우선순위" 블록에 넣었다. 형식·분량·문체 관례 때문에 CARE 세부 항목의 내용을 빼거나 줄이지 않는다.

둘이 다르면 CARE 원문의 요구를 지키고 표기만 국내 관례를 따른다. 예를 들어 국내 제목은 "치험 1례"로 끝나는 경우가 있지만, CARE 는 제목에 "증례보고"(case report)를 넣으라고 하므로 "치험 1례: 증례보고"로 쓴다.

### CARE 원문과 대조해 더한 것

| 섹션 | 원문 근거 | 규칙에 더한 것 |
|---|---|---|
| 제목·핵심 단어 | 항목 1, 2 | 제목에 "증례보고" 필수, 간결하게. 핵심 단어 2~5개(이전 3~5개), 표준 용어로 |
| 초록 | 항목 3 | 증례 문단에 주요 임상 소견, 결론은 하나의 핵심 메시지, 본문의 균형 잡힌 요약. 분량은 국내 관례(6~10문장) 대신 CARE 기준(영문 100~250단어 수준, 학술지 규정 우선)으로 바꿈(사용자 결정) |
| 서론 | 항목 4 | 간단히(자세한 문헌 고찰은 고찰로), 끝의 1~3문장 요약(질문·공백, 중요성, 하나의 핵심 메시지) |
| 환자 정보 | 항목 5 | 동반 질환의 시작·재발과 그 치료 결과, 알레르기(알레르겐·시기·반응), 사회적 지지, 운동·식이·스트레스, 환경, 유전 정보. 식별 정보 제외(원문 Table 2), 90세 이상 |
| 임상 소견 | 항목 6 | 특수한 진찰 방법 설명, 소견이 많으면 표 |
| 타임라인 | 항목 7 | 간단한 병력·가족력, 주소를 행에 |
| 진단 평가 | 항목 8 | 진단 과정을 빠짐없이, 환자 보고 설문, 참고 범위, 진단 가설을 지지·반박하는 문헌 자리, 평가를 끝내지 못한 사정. 치료 중 재평가와 상병명 유지 여부(사용자 요청) |
| 치료 개입 | 항목 9, Table 3 | 개입마다 대상 증상, 약재 학명·사용 부위·제조사(있을 때), 액제 농도, 생활 지도의 종류·빈도·강도·시기 |
| 추적 관찰 | 항목 10 | 이상반응은 모든 증례에서 밝히고, 환자의 표현·빈도·정도·조치까지. 다른 의료진 치료가 결과에 미쳤을 수 있는 영향 |
| 고찰 | 항목 11 | 임상시험·다른 증례보고와의 비교, 후속 연구 제언의 문헌 근거, 기전은 관찰 설명에 도움이 될 때만, 결론은 짧게 |
| 환자 관점 | 항목 12 | 삶의 질에 미친 영향, 보호자의 대리 진술 표시 |
| 동의 | 항목 13 | 보호자·가족 동의, 사진·영상·90세 이상·희귀 질환이면 별도 동의 가능성 |

원문과 이미 맞던 것(예: 임상 소견은 진료 시작 시점, 경과 중 소견은 추적 관찰로, 9c 변경 이유, 이상반응 유무 명시, 단일 증례를 일반화할 수 없음)은 그대로 두었다.

### 원문이 정하지 않아 국내 관례·기존 규칙을 따른 것

- 약재 용량의 단위: 원문은 약재의 "양"을 쓰라고만 한다(Table 3). 기록에 단위가 없으면 숫자만 쓰고 단위를 붙이지 않는다는 기존 규칙을 유지했다.
- 문단 수, 문장 수, 표 칸 구성, 날짜 표기("첫 기록일 +N일")는 국내 관례와 이 도구의 규칙을 따른다. 원문에 숫자가 있는 분량(핵심 단어 2~5개, 초록 100~250단어, 초록 배경·결론 한두 문장, 서론 끝 1~3문장)은 원문을 따른다.

프롬프트 버전: SW-D v7, SW-R v7 (backend/src/llm/promptRegistry.ts).

## 반영한 공통 관례

- **문체**: 과거시제 평서체("~하였다"), 존댓말·차트식 어미("~함") 없음. 용어 첫 등장은 "한글(영문 전체 이름, 약어)". 숫자와 단위 띄어쓰기("50 mg", "0.25×30 mm"), 범위 "~", 점수 "○점에서 ○점으로".
- **기록에 없는 항목은 쓰지 않는다**: 5편 모두 "~는 기록되지 않았다" 같은 부재 문장이 없다. 프롬프트에 금지 규칙을 두고, 최초 초안에서는 코드(`studyWrite/absenceFilter.ts`)로 한 번 더 걸러 notes 에 알린다. 서론·고찰·동의, 검사 음성 소견, 환자 진술, 이상반응 문장, [확인 필요] 표시는 거르지 않는다.
- **환자 정보**: 하위 제목 없는 서술 문단. 나이·성별로 시작해 주소 → 현병력 → 과거력·복용약 → 가족력 → 사회력 순. 초진 시점까지만 쓴다.
- **임상 소견**: 초진 활력징후, 신체 진찰, 맥진·설진·복진, 계통적 문진(식욕·소화·대변·소변·수면 등)을 한 문단에.
- **진단 평가**: "검사명(날짜): 결과", 척도는 "○점(등급)". 척도 설명·절단점은 문헌이 필요하므로 [문헌 보완 필요]. 변증은 근거(증상·설·맥)를 나열하고 "~로 변증하였다".
- **치료 개입**: 종류별 문단(한약 → 침·전침 → 약침·뜸·부항 → 양약·기타). 한약은 처방마다 기간·복용법·구성을 "(1) … (2) …"로 빠짐없이. 침은 빈도·규격·혈위(WHO 코드)·유침 시간·자극. 양약 유지·변경 여부를 밝힌다. 혈위 코드는 용어 사전에서 기록에 나온 혈위만 목록으로 준다(코드를 지어내지 않게).
- **타임라인**: 논문들은 그림 또는 표로 5~15개의 사건 마디를 둔다. 방문마다가 아니라 사건마다 행을 만들고(발병·첫 내원·처방 시작/변경·평가 시점·호전/악화 전환점·생활 사건·종결), 칸은 짧은 명사구로. 보통 6~12행. CARE 템플릿의 네 칸(날짜 | 경과 요약 | 진단 검사 | 치료 개입)은 유지.
- **추적 관찰**: 평가 시점별 단락, 단락 첫머리에 시점, 척도 점수 연쇄("21-20-8-15-3"), 이상반응 한 문장.
- **고찰**: 증례 요약 → 변증·치료 선택 근거(기전은 [문헌 보완 필요]) → 관찰된 경과의 해석 → 해석을 흐리는 요인 → 한계 "첫째, 둘째" → 의의·후속 연구.
- **질문(SW-Q2)**: 증례보고에 들어가는데 기록에 자주 빠지는 정보(초진 활력징후, 검사 날짜·결과, 침 규격·유침, 한약 복용법, 양약 유지 여부, 평가 시점, 동의·IRB)를 먼저 고려.

## 일부러 따르지 않은 것

- 효과를 단정하는 표현("유효하며", "~로 호전된" 같은 인과 제목). 해석 범위 원칙(P5)에 맞지 않는다.
- 논문의 오기·수치 불일치(혈위 코드 오기, 초록과 본문 수치 불일치, 날짜 오타).
- 영문 초록만 두는 구성, 표·그림의 영문 캡션. 실험용 Write 는 한국어 원고를 만든다.
- 특정 과의 척도·처방·검사를 예시로 넣는 것.
