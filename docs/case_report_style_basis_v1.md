# 실험용 Write 초안 문체·구성 근거 (v1, 2026-10-12)

실험용 Write 의 섹션 초안(SW-D), 고쳐 쓰기(SW-R), 질문(SW-Q2) 프롬프트와 섹션별 쓰기 규칙(`backend/src/studyWrite/careItems.ts` 의 `CARE_SECTION_WRITING_RULES`)에 국내 한의 학술지 증례보고의 서술 관례를 반영했다. 근거 논문은 다음 5편이다 (연구실 제공 PDF).

| 학회지 | 주제 |
|---|---|
| 대한한방내과학회지 41(6), 2020 | 뇌경색 후 지남력장애·현훈, 성향정기산가미방 |
| 한방신경정신과학회지 31(3), 2020 | 제2형 양극성 장애 주요우울 삽화, 복합 한방 치료 |
| 대한한방내과학회지 45(2), 2024 | 길랑바레증후군, 침·전침 |
| 대한한방내과학회지 45(2), 2024 | COVID-19 후 알츠하이머 치매 악화, 억간산가미 |
| 대한한방내과학회지 45(2), 2024 | 섬유근육통 불면, 분심기음 |

예시는 특정 과에 치우치지 않도록 짧고 일반적인 것만 넣었다. 논문 문장을 옮기지 않았다.

## 반영한 공통 관례

- **문체**: 과거시제 평서체("~하였다"), 존댓말·차트식 어미("~함") 없음. 용어 첫 등장은 "한글(영문 전체 이름, 약어)". 숫자와 단위 띄어쓰기("50 mg", "0.25×30 mm"), 범위 "~", 점수 "○점에서 ○점으로".
- **기록에 없는 항목은 쓰지 않는다**: 5편 모두 "~는 기록되지 않았다" 같은 부재 문장이 없다. 프롬프트에 금지 규칙을 두고, 최초 초안에서는 코드(`studyWrite/absenceFilter.ts`)로 한 번 더 걸러 notes 에 알린다. 서론·고찰·동의, 검사 음성 소견, 환자 진술, 이상반응 문장, [확인 필요] 표시는 거르지 않는다.
- **환자 정보**: 하위 제목 없는 서술 문단. 나이·성별로 시작해 주소 → 현병력 → 과거력·복용약 → 가족력 → 사회력 순. 초진 시점까지만 쓴다.
- **임상 소견**: 초진 활력징후, 신체 진찰, 맥진·설진·복진, 계통적 문진(식욕·소화·대변·소변·수면 등)을 한 문단에.
- **진단 평가**: "검사명(날짜): 결과", 척도는 "○점(등급)". 척도 설명·절단점은 문헌이 필요하므로 [문헌 보완 필요]. 변증은 근거(증상·설·맥)를 나열하고 "~로 변증하였다".
- **치료 개입**: 종류별 문단(한약 → 침·전침 → 약침·뜸·부항 → 양약·기타). 한약은 처방마다 기간·복용법·구성을 "(1) … (2) …"로 빠짐없이. 침은 빈도·규격·혈위(WHO 코드)·유침 시간·자극. 양약 유지·변경 여부를 밝힌다. 혈위 코드는 용어 사전에서 기록에 나온 혈위만 목록으로 준다(코드를 지어내지 않게).
- **타임라인**: 논문들은 그림 또는 표로 5~15개의 사건 마디를 둔다. 방문마다가 아니라 사건마다 행을 만들고(발병·첫 내원·처방 시작/변경·평가 시점·호전/악화 전환점·생활 사건·종결), 칸은 짧은 명사구로. 보통 6~12행. CARE 템플릿의 네 칸(날짜 | 경과 요약 | 진단 검사 | 치료 개입)은 유지.
- **추적 관찰**: 평가 시점별 단락, 단락 첫머리에 시점, 척도 점수 연쇄("21-20-8-15-3"), 이상반응 한 문장.
- **고찰**: 증례 요약 → 변증·치료 선택 근거(기전은 [문헌 보완 필요]) → 관찰된 경과의 해석 → 해석을 흐리는 요인 → 한계 "첫째, 둘째" → 의의·후속 연구.
- **질문(SW-Q2)**: 증례보고에 들어가는데 기록에 자주 빠지는 정보(초진 활력징후, 검사 날짜·결과, 침 규격·유침, 한약 복용법, 양약 유지 여부, 평가 시점, 동의·IRB)를 먼저 고려.

## 일부러 따르지 않은 것

- 효과를 단정하는 표현("유효하며", "~로 호전된" 같은 인과 제목). 해석 범위 원칙(P5)에 맞지 않는다.
- 논문의 오기·수치 불일치(혈위 코드 오기, 초록과 본문 수치 불일치, 날짜 오타).
- 영문 초록만 두는 구성, 표·그림의 영문 캡션. 실험용 Write 는 한국어 원고를 만든다.
- 특정 과의 척도·처방·검사를 예시로 넣는 것.

## 측정 (임교수님 사례, 같은 질의응답으로 다시 생성)

| 항목 | 전 | 후 |
|---|---|---|
| 타임라인 행 수 | 15~32 | 9~11 |
| 부재 문장(환자 정보·임상 소견·진단 평가·추적 관찰) | 섹션마다 1~3개 | 0 (코드로 걸러 notes 에 기록) |
| 치료 개입의 처방 구성 | 일부만, 나머지는 "조정되었다" | 4개 처방 모두 (1)~(4)로 기간·구성 |
| 서론의 일반 의학 지식 문장 | 있음 | 없음 (환자 사실 + [문헌 보완 필요]) |
| 혈위 WHO 코드 | 없음 | 기록에 나온 혈위 모두 병기 |
