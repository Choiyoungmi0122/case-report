# 사용자 한의사 설문 문항 v1 (구글폼 입력용)

- 대상: 집단 2 사용자 한의사 (증례보고를 써 본 적이 없거나 적은 한의사). 전문가(집단 1)용 설문은 문항이 달라 따로 만든다.
- "폼 제목", "폼 설명", "쪽 제목", "쪽 설명"은 구글폼의 같은 이름 칸에 그대로 넣는다.
- 설문은 두 개다: 실험 직전 설문, 사후 설문(실습 후). 배경 문항은 이미 받았으므로 넣지 않는다.
- **[CRF]** 표시는 증례기록서 ver 1.0 별첨 1-2의 문장 그대로다. 고치지 않는다.
- **[추가]** 표시는 CRF에 없는 문항이다. 넣을지는 연구자가 정한다.
- 이름과 이메일은 받지 않는다. 실험번호만 받는다.
- 구글폼 설정: "이메일 주소 수집" 끔, "응답 1회로 제한" 끔

## 실험 직전 설문

배경 문항(직위, 임상 경력, 증례보고·CARE·AI 사용 경험)은 모집 때 구글폼으로 이미 받았으므로 여기서 다시 묻지 않는다. 실험번호로 그 응답과 연결한다.

**폼 제목:** [실습 전] 증례보고 작성에 대한 생각

**폼 설명:**

> 연구과제명: AI 기반 증례보고 작성 지원 시스템의 한의사 대상 사용성 평가
>
> 시스템을 써 보시기 직전에 작성하는 짧은 설문입니다. 2분쯤 걸립니다.
>
> 증례보고를 쓰는 일과 AI가 쓴 초안에 대해 지금 어떻게 생각하시는지 여쭙니다. 선생님의 실력을 평가하는 설문이 아니고 정답도 없습니다. 지금 드는 생각대로 답해 주세요.
>
> 실습이 끝난 뒤 같은 질문을 한 번 더 드립니다. 이름은 적지 않고 실험번호만 적습니다.

| 번호 | 문항 | 유형 | 선택지 |
|---|---|---|---|
| 0 | 연구용 고유 ID (실험번호) | 단답형, 필수 | 도움말: 연구자가 알려 준 번호를 적어 주세요. 예: T1 |
| 1 | 앞으로 증례보고를 직접 써 볼 생각이 얼마나 있으십니까? | 선형 배율 0~10, 필수 | 0: 전혀 없다 / 10: 꼭 써 보고 싶다 |
| 2 | 위와 같이 답한 이유를 적어 주세요. | 장문형, 선택 | |
| 3 | 지금 진료 기록만 가지고 혼자 증례보고 초안을 쓸 수 있다고 생각하십니까? | 선형 배율 0~10, 필수 | 0: 전혀 못 쓸 것 같다 / 10: 충분히 쓸 수 있다 |
| 4 | 지금 혼자 증례보고를 쓴다면 어디가 가장 막힐 것 같으십니까? | 장문형, 선택 | |
| 5 | AI가 진료 기록으로 증례보고 초안을 써 준다면, 그 내용을 어느 정도 믿고 쓰실 것 같으십니까? | 선형 배율 0~10, 필수 | 0: 전혀 믿지 않는다 / 10: 전적으로 믿는다 |
| 6 | 오늘 실습에서 기대하는 점이나 궁금한 점이 있으면 적어 주세요. | 장문형, 선택 | |

모두 CRF에 없는 추가 문항이다. 1, 3, 5번은 실습 후에 같은 문장으로 다시 묻는다.

확인 메시지: 응답이 저장되었습니다. 연구자의 안내를 기다려 주세요.

## 실험 후 설문

**폼 제목:** [사후 설문] AI 기반 증례보고 작성 지원 시스템 사용성 평가

**폼 설명:**

> 연구과제명: AI 기반 증례보고 작성 지원 시스템의 한의사 대상 사용성 평가
>
> 가상환자 실습을 마친 뒤 작성하는 설문입니다. 7~10분쯤 걸립니다.
>
> 오늘 써 보신 시스템에 대한 생각을 여쭙니다. 선생님을 평가하는 설문이 아니고, 좋게 답하실 필요도 없습니다. 느끼신 그대로 답해 주시는 것이 시스템을 고치는 데 가장 도움이 됩니다.
>
> 실습 전 설문에 적으신 것과 같은 실험번호를 적어 주세요.

첫 문항: 연구용 고유 ID (실험번호), 단답형, 필수

### CRF 사후 사용성 및 안전성 평가 (7점 척도, 19문항)

유형: 모두 선형 배율 1~7, 필수. 왼쪽 라벨 "전혀 그렇지 않다", 오른쪽 라벨 "매우 그렇다". 영역(A~G)마다 쪽을 나누고, 쪽 제목에는 아래 영역 이름을, 쪽 설명에는 영역 아래 적힌 문장을 넣는다.

첫 쪽(A) 설명 앞에 넣을 안내문 [CRF]:

> 가상환자 시나리오 실습 과업을 완수한 후, 각 문항에 대한 본인의 체감 만족도에 체크해 주십시오. (1: 전혀 그렇지 않다 ~ 7: 매우 그렇다)

**A. 시스템 사용성 및 UI 편의성**

쪽 설명: 화면과 진행 순서가 쓰기 편했는지 여쭙니다.

| 번호 | 문항 |
|---|---|
| A-Q1 | 시스템의 전체적인 사용 흐름은 직관적이고 이해하기 쉬웠다. |
| A-Q2 | 각 단계별로 사용자가 수행해야 할 과업이 명확하게 제시되었다. |
| A-Q3 | 시스템 화면 레이아웃 및 기능 배치는 복잡하지 않고 다루기 쉬웠다. |

**B. 증례보고 구조 및 CARE 가이드라인 이해도**

쪽 설명: 증례보고의 구성과 CARE 지침을 이해하는 데 도움이 되었는지 여쭙니다.

| 번호 | 문항 |
|---|---|
| B-Q1 | 시스템은 증례보고의 표준 학술 구조를 파악하는 데 유용했다. |
| B-Q2 | 시스템은 CARE 지침의 각 섹션이 요구하는 임상 정보를 이해하는 데 도움이 되었다. |
| B-Q3 | 비구조화된 임상 데이터가 학술적 서술로 연결되는 메커니즘을 이해할 수 있었다. |

**C. EMR/SOAP 임상 정보 정리 및 선별력**

쪽 설명: 진료 기록에서 필요한 내용을 골라 정리하는 데 도움이 되었는지 여쭙니다.

| 번호 | 문항 |
|---|---|
| C-Q1 | 시스템은 원천 기록에서 필요한 핵심 데이터를 필터링하는 데 도움을 주었다. |
| C-Q2 | 여러 회차의 복잡한 경과 기록을 시계열적으로 정돈하는 데 유용했다. |
| C-Q3 | 자료에 존재하지 않는 임상 정보를 사용자가 임의로 허구 작성하지 않도록 주의 환기를 시켜주었다. |

**D. 누락 정보 및 추가 확인 필요 항목 인식 (안전성)**

쪽 설명: 기록에 빠진 정보나 더 확인이 필요한 내용을 알아보는 데 도움이 되었는지 여쭙니다.

| 번호 | 문항 |
|---|---|
| D-Q1 | 시스템이 제시한 누락 정보 질문은 원본 데이터의 취약점을 인지하는 데 효과적이었다. |
| D-Q2 | 원천 기록에서 즉각 확인 가능한 정보와 전문가의 검토(컨설트)가 필요한 영역을 구분하는 데 도움을 주었다. |
| D-Q3 | 한의학적 변증, 치료 근거 등 기록만으로 단정하기 어려운 섹션을 신중하게 검토하도록 유도했다. |

**E. AI 초안 무비판적 수용 방지 경험**

쪽 설명: AI가 쓴 초안을 읽고 다루면서 느끼신 점을 여쭙니다.

| 번호 | 문항 |
|---|---|
| E-Q1 | 실습을 진행하며 AI 초안을 무비판적으로 수용하지 않고, 텍스트 근거를 직접 대조·검토해야 함을 인지했다. |
| E-Q2 | 시스템은 AI가 제시한 문장 중 추가 검증이 필요한 도출 결함이나 할루시네이션 의심 요소를 고민하게 만들었다. |
| E-Q3 | 결과물에 과도하게 의존하기보다, 임상의 본인의 주도적 편집 권한과 책임성을 체감하게 했다. |

**F. Review AI 및 최종 산출물 만족도**

쪽 설명: 마지막에 보신 학습 기록과 Word 문서 등 결과물에 대해 여쭙니다.

| 번호 | 문항 |
|---|---|
| F-Q1 | Review AI의 섹션 교정 및 피드백 기능은 초안의 학술적 완성도를 높이는 데 기여했다. |
| F-Q2 | 최종 도출된 텍스트 및 파일 내보내기(Word export) 결과물은 지도교수 피드백을 받기 위한 초안 자재로서 충분한 가치가 있어 보였다. |

**G. 임상 실무 및 교육적 도움 정도**

쪽 설명: 이 시스템이 증례보고 쓰는 법을 배우는 데 쓸모가 있을지 여쭙니다.

| 번호 | 문항 |
|---|---|
| G-Q1 | 본 시스템은 실제 현장에서 증례보고 작성을 체계적으로 학습하기 위한 도구로 유용하다. |
| G-Q2 | 이 도구를 지속적으로 활용한다면 CARE 가이드라인을 준수하는 올바른 기록 서술 습관을 기르는 데 도움이 될 것 같다. |

주의: D-Q1(누락 정보 질문)과 F-Q1(Review AI)은 이번 세션에서 참여자가 써 보지 않는 기능이다. 문항은 그대로 두고, 물으면 "오늘 써 보신 범위에서 느끼신 대로 답해 주세요"라고 모두에게 같은 말로 안내한다.

## 추가 문항을 넣은 이유

| 문항 | 보려는 것 |
|---|---|
| 직전 1, 사후 I-1 | 써 보려는 동기가 실습 전후로 달라졌는지 |
| 직전 3, 사후 I-2 | 혼자 쓸 수 있다는 자신감이 달라졌는지 |
| 직전 5, 사후 I-3 | AI 초안에 대한 신뢰가 달라졌는지 |
| 직전 4 | 인터뷰 2번 질문("해 보니 어땠나요")의 기준 |
| 직전 6 | 무엇을 기대하고 왔는지. 사후 I-4 ~ I-6과 견주어 본다 |
| H-1 ~ H-9 | 어떤 기능이 배우는 데 도움이 되었다고 느꼈는지 (CRF는 시스템 전체만 묻는다) |
| I-4 ~ I-6 | 괜찮았던 기능, 있었으면 하는 기능, 불편한 점. 인터뷰 전에 글로 먼저 받는다 |
| I-7 | 다시 쓸 의향 |

참여자가 10명이라 추가 문항의 숫자는 전후 차이를 통계로 검정하는 용도가 아니라, 참여자별 변화를 인터뷰 내용과 함께 기술하는 용도다.

시간: 사후 설문은 CRF 19문항만으로 5분쯤 걸린다. H와 I를 모두 넣으면 9~10분이 될 수 있다. 시간이 빠듯하면 I-4 ~ I-6은 인터뷰에서 묻고 폼에서는 뺀다.
