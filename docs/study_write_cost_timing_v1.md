## 같이 발견한 문제와 조치

1. **비식별기가 일반 단어·약재명을 환자 이름으로 가렸다** (정확도 문제).
   임교수님 기록에서 14종이 `[PATIENT_NAME_n]` 으로 바뀌었다: 백두구, 백복령, 반하제, 선복화, 오미자(약재), 기록일, 이완기, 심박이, 편하고, 이미지, 어려운, 기재해, 한의원, 지금은.
   원인은 `deid/rules.ts` 의 첫 규칙(흔한 성씨 + 한글 1~3자 + 조사/공백)과 "OO 환자" 규칙. 답변 문장 "환자에게"는 "환자[PATIENT_NAME_1]", "공유하는"은 "[PATIENT_NAME_2]는"으로 바뀌었다.
   **조치 (사용자 결정 2026-10-11, 참여자가 이름을 지우고 올리므로 이름은 넘어간다):** 비식별 프로필 `anonymized_record` 를 추가했다. 실험용 Write 의 기록 전처리·답변·채팅 지시·연구 내보내기에서만 쓰고, 표지가 분명한 이름("환자명: 홍길동", "45세 남성 홍길동")만 가린다. 기관 이름이 없는 "한의원", "타병원"도 두게 했다. Scaffold 와 일반 Write 는 기존 규칙 그대로다. 회귀 테스트 `tests/deid/deid.test.ts` 에 추가.
2. **타임라인이 중간에서 끊겼다** (+67일까지만, 기록은 +141일). 타임라인 규칙에 "마지막 방문까지, 같은 치료 반복 구간은 묶기"를 추가. 2차 실행에서 +141일까지 15행.
3. **모델이 프롬프트 예시의 자리표시자를 베껴 썼다** ("[PATIENT_NAME_1]에게는"). 원칙 P6 의 예시를 없애고, 입력에 없는 자리표시는 "환자"로 되돌리는 보호 코드(`dropForeignPlaceholders`)를 초안·수정 체인에 넣었다.
4. **치료 개입이 처방 하나만 예로 들고 나머지를 "기록에 따라 조정"으로 뭉갰다.** 규칙에 "기록의 모든 처방을 구성·용량과 함께, 양 0인 약재는 빼고, 기록에 단위가 없으면 단위를 붙이지 않는다"를 추가. 다시 만들면 4개 처방 구성이 모두 나온다.
5. 임베딩을 4,815번 한 건씩 호출한다(약 25초). 비용은 미미하지만 묶어서 보내면 분석 시간이 줄 수 있다. 공용 전처리 경로라서 Scaffold 실험 중에는 손대지 않았다.
6. 교수님 기록은 상대 일수만 있어 초안 날짜가 "첫 기록일 +N일"로 나온다. 연도 추정은 없었다.
