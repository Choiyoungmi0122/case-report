# 사용자 한의사 세션 진행 대본 v1 (60분)

- 대상: 면허가 있는 수련 중 한의사, 증례보고 작성 경험이 없거나 적은 사람
- 보려는 것: 혼자 쓰기 전에 배우는 도구로서의 역할 — 괜찮았던 기능, 있었으면 하는 기능, AI에 대한 신뢰, 써 보려는 동기의 변화
- 다루는 CARE 항목은 치료 개입, 추적 관찰 및 결과 두 개다.
- 시간 배분은 사전 점검 결과로 조정한다. 아래 숫자는 초안이다.

## 세션 전 준비 (연구자)

- [ ] 서버 실행 확인: 첫 화면이 열리고 "실험용 Scaffold 시작" 버튼이 보인다
- [ ] 가상환자 EMR 인쇄본 1부, 펜
- [ ] 실험번호 확인 (CRF와 같은 번호: T1, T2 …)
- [ ] 녹음기 또는 녹음 앱, 화면 녹화(온라인일 때)
- [ ] CRF(사후 설문 19문항) 인쇄본 또는 폼 링크
- [ ] 관찰 기록지(이 문서 맨 아래), 시계
- [ ] 구글폼 사전 응답(작성 경험, 교육 경험, AI 사용 정도) 확인

설문과 인터뷰에 22분을 쓴다. 실습은 20분이고 CARE 항목은 치료 개입, 추적 관찰 및 결과 두 개다. 항목마다 참여자가 먼저 두세 문장으로 초안을 써 본 뒤 AI 초안과 비교한다.

실험 사례는 미리 검토해 저장해 둔 분석 결과와 AI 초안을 쓴다. "CARE 구조 분석 시작"을 누르면 1~2초 안에 다음 화면으로 넘어가고, 모든 참여자가 같은 AI 초안을 본다.

## 1. 안내와 동의 (5분)

> "오늘은 진료 기록을 바탕으로 증례보고를 쓰는 과정을 도와주는 시스템을 직접 써 보시고, 써 본 느낌을 말씀해 주시면 됩니다. 선생님의 실력을 평가하는 자리가 아니고, 시스템을 평가하는 자리입니다. 정답은 없으니 평소 생각하시는 대로 하시면 됩니다."
>
> "환자는 실제 환자가 아니라 교육용으로 만든 가상환자입니다."
>
> "진행 중에 말씀하신 내용은 정확히 기록하기 위해 녹음합니다. 괜찮으실까요?"

- 설명문을 전달하고 동의서에 서명을 받는다.
- 녹음을 시작한다.

## 2. 사전 질문 (3분)

답을 그대로 받아 적는다. 숫자는 꼭 적는다. 끝나고 같은 질문을 다시 묻는다.

1. "앞으로 증례보고를 직접 써 볼 생각이 얼마나 있으세요? 0에서 10으로 말씀해 주신다면요. 이유도 말씀해 주세요."
2. "지금 혼자 증례보고를 쓴다면 어디가 가장 막힐 것 같으세요?"
3. "AI가 진료 기록으로 증례보고 초안을 써 준다면, 그 내용을 어느 정도 믿고 쓰실 것 같으세요? 0에서 10으로요."

## 3. EMR 정독 (5분)

인쇄본을 건넨다.

> "이 환자를 선생님이 직접 진료한 환자라고 생각하고 읽어 주세요. 표시하거나 메모하셔도 됩니다. 실습하는 동안 계속 옆에 두고 보셔도 됩니다."

- 무엇을 주의해서 보라는 말은 하지 않는다.
- 5분이 되기 전에 다 읽었다고 하면 바로 다음으로 넘어간다.

## 4. 사례 불러오기와 분석 시작 (1분)

참여자가 직접 한다. 연구자는 순서만 알려 준다.

1. "실험용 Scaffold 시작"을 누른다.
2. 실험번호를 입력하고 참여 방식을 고른 뒤 "기록 입력하기"를 누른다.
3. "실험 사례 불러오기"를 누른다. 방문 6개가 채워진다. 내용은 고치지 않는다.
4. "CARE 구조 분석 시작"을 누른다. 곧바로 다음 화면이 열린다.

주의: 불러온 기록을 한 글자라도 고치면 저장해 둔 결과를 쓰지 않고 새로 분석한다(약 2분, 다른 참여자와 다른 초안). 고쳤다면 "실험 사례 불러오기"를 다시 누른다.

## 5. 시스템 실습 (20분)

> "이제 시스템을 써 보겠습니다. 화면 안내를 따라가시면 됩니다. 하시면서 드는 생각을 소리 내어 말씀해 주시면 도움이 됩니다."

진행 범위:

- 1단계 증례 이해 (약 2분, 종이로 이미 읽었으므로 짧게): 화면에서 기록을 다시 훑으며 메모를 남긴다. 메모는 "메모 추가"를 누르면 바로 저장되고, 메모가 없어도 다음으로 넘어갈 수 있다. 회차 버튼(1회차~6회차)으로 방문을 오갈 수 있다. 방문마다 접혀 있는 "AI 메모 추천"을 펼쳐 봤는지 관찰 기록지에 적는다. "다음: CARE 항목 작성"을 누른다.
- 진행 방법, CARE 설명, 작성 예시 (약 3분): 2단계 화면 맨 위의 "진행 방법과 예시"와 그 아래 "증례보고는 이렇게 구성됩니다 (CARE 지침)"를 연구자가 함께 읽어 준다. 예시의 환자(요통 환자)는 오늘 실습할 환자와 다른 환자다. "이 환자라면 이렇게 씁니다" 표에서 환자 정보, 치료 개입, 추적 관찰 및 결과의 작성 예를 보여 준다. 모든 참여자에게 같은 순서와 같은 말로 안내한다.
  > "CARE 지침은 증례보고에 무엇을 적어야 하는지 정리한 기준입니다. 오늘은 그중 두 항목을 연습합니다. 항목마다 세 걸음입니다. 먼저 선생님이 기록을 보고 두세 문장으로 직접 써 보십니다. 예시처럼 짧게 쓰시면 되고, 잘 쓰려고 하지 않으셔도 됩니다. 그다음 AI가 쓴 초안을 선생님이 쓴 것과, 그리고 기록과 비교하면서 읽습니다. 기록과 다르거나 확인이 필요한 문장만 눌러서 표시하고 이유를 적으시면 됩니다. 다시 누르면 표시가 풀립니다. 마지막으로 두 초안이 무엇이 달랐는지 한 줄 적습니다."
- 2단계 CARE 항목 작성 (약 15분, 항목당 7분 안팎)
  - 먼저 화면 위의 "증례보고는 이렇게 구성됩니다 (CARE 지침)" 상자를 함께 읽는다 (약 1분).
  - 아래 두 항목을 위에서부터 차례로 진행한다.
    1. 치료 개입
    2. 추적 관찰 및 결과
  - 항목마다: 맨 위 노란 "CARE 기준" 상자와 작성 예 읽기 → "내 초안"에 두세 문장 쓰기(근거 고르기는 접혀 있는 선택 사항) → "다음: 정보 충분성 확인" → 정보가 충분한지 3문항(답을 고르면 "기록에서 관련된 부분 보기"를 펼쳐 볼 수 있다) → "내 정리 저장하고 AI 초안 보기" → AI 초안을 읽으며 기록과 다르거나 확인이 필요한 문장만 눌러 표시하고 이유 저장(표시할 문장이 없으면 그대로 진행) → "AI 초안에 빠진 내용"(선택) → "내 초안과 AI 초안을 비교해 보니" 한 줄 → "검토를 마쳤습니다. 이 항목 완료"
  - 항목 하나에 7분이 넘으면 "다음 항목"으로 넘어가도 된다고 알려 준다. 두 항목을 끝까지 하는 것이 목표다.

화면의 색 구분 (참여자가 물으면 알려 준다):

| 색 | 의미 |
|---|---|
| 노랑 | CARE가 요구하는 기준 |
| 회색 | 환자 원기록 |
| 파랑 | AI가 쓴 초안 |
| 초록 | 내가 쓴 초안과 내가 정리한 내용 |

### 연구자가 지킬 것

| 상황 | 대응 |
|---|---|
| 사용법을 묻는다 (어디를 눌러요?) | 알려 준다. 관찰 기록지에 "도움"으로 적는다 |
| 내용 판단을 묻는다 (이건 넣어야 해요?) | "선생님 생각대로 하시면 됩니다"라고 답한다 |
| AI 문장이 맞는지 묻는다 | "기록과 비교해서 판단해 보시겠어요?"라고 답한다 |
| 한 곳에서 3분 넘게 멈춘다 | "어떤 점이 어려우세요?"라고 묻고 기록한다 |
| 빠르게 넘어간다 | 막지 않는다. 위치를 적어 두고 인터뷰에서 묻는다 |
| 시간이 모자란다 | 진행 중인 항목까지만 마치고 6번으로 넘어간다 |

말하지 않을 것: 이 사례에서 무엇을 찾아야 하는지, 어느 문장이 틀렸는지, 무엇이 빠졌는지.

말해도 되는 것: CARE 지침이 무엇인지, 각 항목에 어떤 내용이 들어가는지. 화면의 노란 상자에 있는 내용은 일반 기준이라 설명해도 된다.

## 6. 학습 기록과 Word 결과 확인 (2분)

> "지금까지 하신 내용이 어떻게 정리되는지 보겠습니다."

- CARE 항목 목록 아래의 "내 학습 기록 보기"를 눌러 기록 화면을 함께 본다.
- "Word로 내보내기"를 눌러 문서를 열어 본다.
- "이 문서를 지도교수께 가져간다면 어떨 것 같으세요?"라고 가볍게 묻는다.

## 7. 사후 설문 (7분)

CRF 사후 설문 19문항(7점)을 작성하게 한다. 작성하는 동안 말을 걸지 않는다.

## 8. 인터뷰 (15분)

사전 질문의 답을 옆에 두고 진행한다.

| 순서 | 질문 | CRF 항목 |
|---|---|---|
| 1 | "증례보고를 직접 써 볼 생각이 지금은 0에서 10으로 얼마인가요?" → 사전 답과 다르면 "무엇 때문에 달라졌나요?" | E |
| 2 | "아까 혼자 쓴다면 ○○에서 막힐 것 같다고 하셨는데, 해 보니 어땠나요?" | B |
| 3 | "AI가 쓴 내용을 지금은 0에서 10으로 얼마나 믿으시나요?" → "믿은 문장과 의심한 문장을 하나씩 짚어 주시겠어요? 왜 그러셨나요?" | D |
| 4 | "배우는 데 가장 도움이 된 단계는 무엇이었나요? 없어도 됐을 단계는요?" | A |
| 5 | "AI 초안을 보기 전에 먼저 적게 한 건 어떠셨어요?" | D |
| 6 | (빨리 넘어간 곳이 있었다면) "○○ 단계는 빨리 넘어가셨는데, 어떤 이유였나요?" | A |
| 7 | "이걸 해 보고 나서 혼자 증례보고를 쓴다면, 무엇이 더 있어야 할까요?" | E |
| 8 | "이 환자 기록은 실제 진료 기록 같았나요?" | C |

15분이면 8개를 모두 물을 수 있다. 시간이 모자라면 1, 3, 4, 7번을 우선한다.

마무리:

> "오늘 말씀해 주신 내용은 시스템을 고치는 데 쓰겠습니다. 감사합니다."

- 2차 세션 참여가 가능한지 묻는다.
- 녹음을 끝낸다.
